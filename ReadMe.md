# Clio
### Ryann Kim Sesgundo (Master Piece of Paper)

> A platform for novels, stories, and poetry — where every chapter has a soundtrack.

Clio is a web-based reading platform developed in the Philippines, inspired by the spirit of storytelling and the Muse of history herself. Built with **React**, **TypeScript**, and **Vite**, Clio reimagines how readers experience fiction by letting authors add **background music to specific chapters and scenes**, creating an immersive, cinematic reading journey.

---

## ✨ Features

- **Novel, Story & Poetry Publishing** — A dedicated space for writers to share their work
- **Chapter-Based Background Music** — Authors can attach music to specific chapters or scenes, enhancing emotional impact
- **Clean, Modern Reader Interface** — Distraction-free reading built for long sessions
- **Fast & Lightweight** — Powered by Vite for lightning-fast dev and build times
- **Type-Safe Codebase** — Built with TypeScript for reliability and maintainability

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/RyannKim327/clio.git
   cd clio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and visit `http://localhost:5173`

## 🎯 Why "Clio"?

In Greek mythology, **Clio** is the Muse of history, stories, and heroic poetry. She is one of the nine Muses, daughters of Zeus and Mnemosyne (Memory), and she presides over the chronicles that shape our understanding of the world.

Clio was chosen as the name for this platform because:

- She represents the **preservation and celebration of stories**
- She embodies the **power of narrative** to move, teach, and inspire
- Her name is short, memorable, and carries centuries of literary heritage

Just as Clio the Muse inspired ancient poets, **Clio the platform** aims to inspire modern writers and readers — now with the added dimension of music.
